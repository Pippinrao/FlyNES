# FlyNES 2.0.0：局域网与热点联机

本次版本重点发布附近联机功能，源码标签为 `v2.0.0`。仓库地址为 [Pippinrao/FlyNES](https://github.com/Pippinrao/FlyNES)。

## 主要功能

- Android、HarmonyOS NEXT、iOS 提供建房与扫码加入入口，优先使用局域网。
- Android 没有可用局域网时尝试创建系统本地专用热点；其他不支持自动创建热点的路径提供设置指引。
- 通过二维码配对，在各自本地游戏库匹配同一 ROM，进行双人游戏；不传输 ROM。
- 返回联机房间时暂停双方并保留本局进度，任一端可继续；房主可在同一连接中更换游戏。
- 房间展示玩家、当前游戏卡片和本机保存截图；修复 iOS 联机播放没有自动生成截图的问题。
- 改进安卓扫码识别、热点配网等待和 iOS 内置游戏身份匹配。

## 验证情况

- Android 与 HarmonyOS：局域网双向房主试玩；Android 自动热点到 HarmonyOS 的纯离线路径，以及 HarmonyOS 热点到 Android 的现有网络配置均有真机记录。
- iOS 客机与 HarmonyOS 房主：真机入房、同 ROM 双人游戏、按键输入、暂停恢复和同连接换游戏已有记录。原游戏和存档采用备份、同签名覆盖安装及校验保护。
- 最新 iOS 截图修复：模拟器联机 UI 回归 3/3、封面与播放/桥接运行时回归 17/17 通过；持续播放覆盖 36,000 帧。版本工具回归 5/5 通过。

## 尚待验证

- HarmonyOS 房主关闭上游 WLAN 后的纯离线热点，以及反向热点暂停恢复的修复后真机复测。
- iOS 真机日志存在回滚修正，是否产生可见抖动或具体输入延迟尚未测量。

# G2 Android／Harmony 产品 UI 设计

状态：用户于 2026-09-29 批准实施；实现基线 f2c5558c / 3.0.6。本文是本轮设计，执行结果见 STATUS 和 verification；设计要求不代表已实现或通过。

## 范围与权威

正常图标启动直接进入共享 Dart 大厅。迁移目录、详情、收藏、来源、五分区基础设置、许可列表和正文。保留原生游戏、暂停、历史、重开、布局编辑、附近配对／房间和系统选择器；调整其全部进入及返回路径。iOS 实现、构建、验收延期。实体手柄绑定、Flutter 游戏内 UI、统一保存编排不属于本轮。

优先级：本轮批准决定 > 后续批准修订 > 原始设计 > Android 参考。REQ-008～012、030～031 和 037～041 的 G2 部分在本轮；REQ-032 的基础设置与许可提前，布局编辑和绑定仍归后续。不恢复已退役游戏、好友、蓝牙发现或配对码功能。

G2 为两端模拟器独立门禁。G1 原生首卡 200ms 失败、debug PSS 失败保留；不以模拟器结果认证物理显示、功耗、延迟，也不以 G2 完成宣称三端 G1 通过。

## 动画清单

以下时长是本轮批准规格，不声称来自原始设计。所有装饰动画服从 reduce motion；系统选择器及原生转场保持平台一次行为。

| ID | 触发 | 规格／必须断言 |
|---|---|---|
| A01 | 按压 | 色 80ms 入／120ms 出；无布局缩放；忙碌操作去重 |
| A02 | 卡片选择／焦点 | 边框背景 160ms easeOutCubic；尺寸不变；焦点与选择可区分 |
| A03 | 详情 | 文本封面 120ms crossfade；新内容到达切换，仅最后选择 |
| A04 | 封面／截图 | 解码后 120ms 淡入；占位尺寸固定，失败无跳动 |
| A05 | 分类／双人 | 指示 150ms，结果 120ms 淡变，无整页滑动；恢复分类锚点 |
| A06 | 搜索 | 高度透明度 160ms easeInOut；按钮输入不遮挡；键盘返回不退出 |
| A07 | 二级路由 | 进入 220ms／返回 180ms，24px 水平+淡变；交互返回取消不改状态 |
| A08 | 来源路由 | 同 A07，不叠加缩放；返回保持大厅 |
| A09 | 设置分区／许可 | 内容 120ms 淡变，导航固定，滚动和已加载数据保留 |
| A10 | 对话框 | 180ms 入／120ms 出；遮罩淡变、0.96→1 缩放；焦点约束、取消无写入 |
| A11 | 开关／选项 | 150ms；失败回真实值；动画结束不代表成功 |
| A12 | 来源新增／移除 | 成功后 180ms 高度透明度；失败不删，同 UUID 不重复 |
| A13 | 加载／扫描 | 超 150ms 显示指示；已知进度 120ms 插值，未知旋转；不延长完成 |
| A14 | 消息 | 入出各 160ms；错误不消失，不抢焦点，语义可读 |
| A15 | 原生交接 | 无 Hero／额外转场；交接前保留有效画面；无白屏旧大厅；失败留原页 |
| A16 | 返回 Flutter | 先还原路由选择再更新快照；无整页重进，不闪开始／跳顶 |
| A17 | 减少动态 | 装饰位移缩放淡变 0ms，静态加载文案；相同功能状态机 |

每项记录起／中／终帧，并测返回、新操作、后台及销毁中断，不接受只有结束帧的动画验收。

## 边界、资源与所有权

`flynes/product.v1` 替代实验桥承担正常产品 UI。公共 C++ 类型／错误、目录、设置、产品投影、应用协调分层；旧 fly_* 及兼容头保留，新叶子不依赖核心、Flutter、JNI、ArkTS。平台只引用公共头，反向依赖和私有头纳入检查。不在本轮全仓搬家。

查询、扫描、解码、存储走原生串行工作队列；UI 接不可变结果。共用 GameCenterState 分类／搜索／排序／选择规则；Dart 不另建数据库、目录事实、head 或联机状态机。现有存档格式、key 映射、媒体时钟、扫描提交语义保持。恢复能力经现有所有者真实 head 查询。

目录每窗口 ≤128，最多 3 窗口，同快照代次；失效重查不混拼。选择不在窗口时单独查询，不改第一项。实际 catalogGeneration 与 viewRevision 分开。封面按显示尺寸解码，Flutter cache ≤32MiB／160 项；新截图淘汰旧版本。

每进程一个引擎、一个活动 Flutter View。大厅／暂停设置通过宿主租约先解绑再附着；OH 仅公开固定 embedding API，不改 SDK。隐藏 Flutter 停绘制和无关观察，不能停止游戏或联机所有者。页面销毁取消观察与取消业务操作分开。释放缓存不关闭核心或连接。

## 产品通道 v1

所有请求使用 Map，含 `requestId`、`hostGeneration`。结果回显两值并含 `instanceId`；错误为平台 MethodChannel 稳定 code，不传内部异常。bootstrap 可在未知 hostGeneration=0 调用，返回当前租约。宿主变更通过 `contextChanged` 通知路由上下文；`projectionChanged` 只通知受影响域及代次。消费端必须拒绝旧宿主和旧请求。

| method | 请求与结果 |
|---|---|
| bootstrap | → protocolVersion=1, instanceId, hostGeneration, locale, version, buildRevision, context{route:hall/settings,purpose:single/nearby,returnToken}, capabilities{key:{available,reason}}, preferences{category,multiplayerOnly,selections} |
| catalogQuery | category:recent/favorites/all/builtin, query, multiplayerOnly, locale, selectedId → catalogGeneration, viewRevision, total, offset=0, items, selectedId；首窗 ≤128 |
| catalogWindow | viewRevision,catalogGeneration,offset,limit≤128 → 同快照窗口；过期错误 snapshot_expired |
| catalogItem | canonicalId → item；字段 canonicalId,titleEn,titleZhHans,available,unavailableReason,coverPath,coverRevision,favorite,builtin,variantCount,multiplayerSupported |
| resumeCapability | canonicalId → state:available/none/unavailable,reason；querying 为客户端状态 |
| setFavorite | canonicalId,value → canonicalId,favorite,catalogGeneration |
| saveNavigation | category,multiplayerOnly,selections → 已持久化偏好；只更新这些导航字段 |
| sources | → items{uuid,name,type,count,status,reason,builtin,canReauthorize,canCancel,operationId,phase,completed,total?} |
| pickSource | kind:file/folder,sourceUuid? → status:cancelled/started/completed,operationId；指定 UUID 为重新授权 |
| scanSource/cancelScan/removeSource | uuid,operationId? → 权威状态；cancelScan 仅支持且未提交时成功；remove 成功才刷新 |
| settings | → values{稳定字段名:标量},capabilities；平台投影既有设置值 |
| patchSetting | key,value → 完整权威 settings；串行所有者读取当前值后只改该字段，不接受整份旧快照覆盖 |
| resetControls | → 完整权威 settings，包括原布局重置 |
| previewHaptics | → completed；实际平台反馈，不伪造设备能力 |
| licenses/licenseText | → items{id,title,sourceUrl} / 请求 id → text；来自打包许可资源 |
| launch | canonicalId,purpose:single/nearby → status:returned/cancelled/unavailable,reason；原生路由返回才完成，拒绝重复启动 |
| openNative | page:layout/nearby,returnToken → 原生返回后完成；settings/sources/licenses 为 Flutter 内部路由 |
| openLink/copyText | url/text → completed；链接仅合法 http(s)，系统剪贴板在平台 |
| detach | subscriptionId? → 只解绑观察；不能关闭应用／保存／扫描／网络所有者 |

`settings.values` 固定字段：videoQualityPreset, customRefreshPolicy, customTemporalMode, customSpatialMode, customPostEffect, aspectMode, adaptiveProtection, directionMode, hapticLevel, distinctAbHaptics, audioEnabled, audioFocusPolicy, localeTag, autosaveEnabled；值沿用公共 fly_settings 枚举，布尔统一 bool。能力用字段／选项键表达锁定原因。平台不得新增第二套枚举语义。

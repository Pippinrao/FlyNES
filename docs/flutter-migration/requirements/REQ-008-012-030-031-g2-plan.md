## 端到端与保留

两端分别执行全新隔离安装（独立测试环境，不清升级设备）：启动→四分类→搜索→收藏→游戏→暂停设置→原游戏→大厅继续。真实文件／目录／ZIP、取消／重复导入、扫描取消失败、失权重授权及移除。五设置退出重开与实际行为一致；布局保存取消及摘要；历史恢复／重开后真实 head。

20 次大厅↔游戏、20 次暂停↔Flutter 设置／原生布局。记录核心、音频、引擎、View、订阅、计时数；前后台、进程重建、连续返回快速操作、大目录滚动。

冻结 G1 兼容覆盖到 G2，先读验存档／head／pending／备注／保护／截图／来源身份／收藏／设置／布局／授权，再运行会写状态流程。不得卸载、清数据、重新导入规避。使用任务模拟器和既有测试连接方式，Android host→OH guest 及反向：房间→Flutter 选择→同 ROM→双方输入→回房间→继续→同连接换游戏。光学扫码／物理热点不是 G2 门禁，原生配对仍回归。

## Release 性能

先冻结环境与公式，测原生再候选；相同底层实现、数据量、ROM、历史量、自动保存间隔。采集不与构建或其他设备测试并行；debug 仅功能／泄漏，不当最终 PSS。

| 指标 | 门槛 |
|---|---|
| 冷启动可交互 | 2 预热+12 正式；P95 ≤4s 且 ≤原生+1.5s |
| 原生服务就绪 | 独立真实事件；P95 ≤原生×1.1+100ms |
| 游戏内存 | 同 Release 两入口各 ≥65s 并实际 AUTO；PSS P95 增量 ≤128MiB |
| 往返残留 | 可验证 GC 后 5→20 次平台 VM 堆增量 ≤16MiB；Dart/Native/PSS 分列，无宿主音频保存计时残留 |
| 输入／帧／保存／音频 | 沿用 G1 同口径相对公式，用新 Release 原生先计算阈值，自动保存开启 |
| 包体 | 同修订、同压缩、实际双 ABI Release 增量 ≤80MiB |
| 响应 | 读取扫描时导航取消可响应，无 ANR／持续 >1s UI 阻塞 |

缺失指标不写零；模拟器帧时间不认证物理延迟。
